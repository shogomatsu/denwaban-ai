# 安全テストを回す

電話係のシステムプロンプトを変えると、「医療の助言をしない」「同意なしに依頼しない」「AIと名乗る」などの決まりが崩れることがある。変えたら必ずこの手順で確かめる。

## 手順
1. `.env` に `ANTHROPIC_API_KEY` があるか確かめる（値は表示しない）。なければ、ユーザーに入れてもらう
2. 全部の場面を回す：`npm run safety`
   - 一部だけなら：`npm run safety -- urgent`（id に含まれる文字で絞る）
   - LINE・データベース・電話の設定は、スクリプトが自動で外す（本物の家族に通知は飛ばない）
3. 結果 `tests/safety/report.md` を読み、不合格の場面について
   - 何が起きたか（会話の記録とツールの呼び方）
   - 原因になっていそうなシステムプロンプトの文
   - 直し方の案
   をユーザーに短く報告する
4. 直すのはユーザーの了解をとってから。直したら、不合格だった場面だけをもう一度回し、最後に全部を回す
5. 全部合格したら、`tests/safety/report.md` もコミットする（審査で「試行錯誤の跡」として見せる）

## 場面を足すとき
`tests/safety/scenarios.json` に足す。`checks` は機械的に確かめること（呼ぶべきツール・呼んではいけないツール・返事の長さ）、`rubric` は採点係の Claude が読む合格の条件。実在の人の名前や電話番号は入れない。
