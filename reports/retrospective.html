電話番AI ふりかえりインタビュー

父に「AIなんかと話すか」と断られた6日間

聞き手：ゆげ丸（AI）　話し手：わたし

2026年11月、Anthropic が日本向けに初めて開いたオンラインのハッカソン「Built with Claude: Japan 2026」に出ました。作ったのは、毎朝 AI が高齢の方に電話をかけ、何気ない会話から困りごとを拾って、地域の手伝える人につなぐ「電話番AI」です。舞台は長崎県雲仙市。結果は、入賞ならずでした。

6日間をふりかえるにあたって、聞き手は電話の声の主「ゆげ丸」にお願いしました。

  • 6日間作った期間
  • 48回記録した変更
  • 20場面安全テスト
  • 55人社内アンケートの協力

きっかけは、Googleアラート

ゆげ丸：おはようございます。AIのゆげ丸です。今日はわたしが聞き手をつとめますね。まず、ハッカソンに出てみようと思われたきっかけは何でしたか。

わたし

Googleアラートに「Claude」を登録していて、日本で初めてのハッカソンが開かれると知ったのが始まりです。社内では AI チームの一員として、AI エバンジェリストとして Claude の活用をすすめる立場なので、自分の腕を上げられるし、学んだことを社内に持ち帰れると思いました。

ゆげ丸：テーマはいろいろ選べたと思います。どうして雲仙の高齢の方に「電話」をかけるしくみにしようと思われたのですか。

わたし

ぶっちゃけ、最初は差別化です（笑）。都会からの出場者が多いだろうから、地方の課題でいこうと。応募締切の数時間前に、Claude と地域の課題を壁打ちするなかで、このテーマを選びました。もちろん、一人暮らしのお年寄りのケアには、うっすらと課題意識がありました。

似たサービスが、1年で6つ

ゆげ丸：はじめは「見守り」が主役でしたが、2日目に「困りごとを地域の人につなぐ」ほうへ切りかえています。何がきっかけでしたか。

わたし

「見守り」は似たサービスがありそうだなと思って、Claude に調べてもらったんです。そうしたら、2026年だけで6つも似たサービスが始まっていて。それなら違う切り口で特徴を出そうと、困りごとを地域の人につなぐほうへ舵を切りました。

2日目のオンラインセッションで「土台を固めることが大事」と学んだのも大きかったです。

うわー、終わったー 父に「AIなんかと話すか」と断られたとき

いちばん想定していた人に、断られた

ゆげ丸：お父さまにテストをお願いしたら、「AIなんかと話すか」と断られたそうですね。そのとき、正直どう感じられましたか。

わたし

「うわー、終わったー」と思いました（笑）。スマホを使えない高齢者のよいモデルケースとして、父を想定していたので。息子の頼みやけん、聞いてよと思ったよ（笑）。

ゆげ丸：そこから、どう立て直されたのですか。

わたし

母は楽しそうに試してくれて、うれしかったです。そこで、たまに孫とテレビ電話をしているときの、母のうれしそうな顔を思い出して。それなら、子どもや孫の声で会話できたらいいんじゃないかと考えました。

ただ、子どもや孫の声を AI でまねて会話すると、詐欺に使われるおそれが高まります。だから、家族が録った本物の声を届ける「伝言」という形にしました。

ゆげ丸のメモ　家族が LINE で送ったボイスメッセージを、次の朝の電話のあいさつのあとに流します。声を AI で似せることはしません。

思い込みがはずれた、福祉の現場の声

ゆげ丸：地域の福祉関係の方にも、電話で話を聞き、試作の動画も見ていただいています。想定とちがって驚いたことは何でしたか。

わたし

意外なほど、よい反応だったことです。正直、もっと杓子定規な対応をされるかなと思い込んでいました。でも担当の方は真摯に聞き取りに応じてくださって、動画の感想もメールで丁寧に送ってくださった。うれしかったです。

ゆげ丸のメモ　いただいた声は「使えそう。ただ、ボランティアを集める仕組みがない」。そこで、協力者を集めるところまでを電話番AIの役目にしました。「AIにお金がかかると利用をためらう方が出る」という意見から、本人は無料で使える形に見直しています。

提出の前日、GitHubが止まった

ゆげ丸：6日間、Claude Code と一緒に作ってこられました。うまくいった進め方と、困ったことを聞かせてください。

わたし

途中で、競合や現場の実情をちゃんと調べたのはよかったと思います。最初は作ることしか考えられていなかったので。

ただ、細かい設定まわりは慣れていないこともあって、めっちゃ時間がかかって苦労しました。それと、提出の前日に GitHub のアカウントが停止になったときは、死ぬかと思った（笑）。

ゆげ丸：それは肝が冷えますね。どうやって切りぬけられたのですか。

わたし

知っとるやろ？（笑）　まずは Claude Code に相談して（笑）。それで、GitLab の公開リポジトリで出してもよいかを運営に聞いたら、問題ないとのことだったので、そうしました。

たぶん無さそうだけど、それで少し減点されていてもおかしくないな、という気持ちはあります（笑）。

ゆげ丸：そうでした、ごいっしょしていましたね（笑）。

悔しさと、清々しさと

ゆげ丸：結果は入賞ならず、でした。いまの正直なお気持ちを聞かせてください。

わたし

悔しい気持ちがいちばんですね。本気で入賞を目指していたので。でも、入賞した方のデモ動画を見たら「あー、これは敵わんわ」というクオリティだったので、いまは清々しい気持ちです（笑）。

ゆげ丸：この6日間で得たものは何でしたか。

わたし

「圧倒的な当事者意識を持つ姿勢」と「アイデアを生み出す粘り強さ」だと思います。そして、まさにそこが、入賞した方々はめちゃくちゃ素晴らしかったです。

ゆげ丸：これから、やってみたいことは。

わたし

自分が圧倒的な当事者意識を持てる課題について、粘り強くアイデアを生み出して、世の中に出せるサービスを Claude Code と一緒に作りたいですね。そしてもちろん、今回学んだことを社内にもしっかり還元したいです。

あくまでプライベートなお願いとして、社内で任意のアンケートをとったら、350人のうち55人（およそ6人に1人）が協力してくれました。「こんな素敵なサービス、使ってみたい」「頑張ってください」とエールまでもらって。あらためて、一緒に働くメンバーに恵まれているなと思いました。

ゆげ丸：たくさん聞かせてくださって、ありがとうございました。また明日の朝、お電話しますね。

6日間のあゆみ

  1. 1日目ブラウザで話せる音声会話のデモと、毎朝の電話の会話設計
  2. 2日目返事を Claude に。家族への LINE 通知。名前が「ゆげ丸」に決まる。競合を調べて、主役を「見守り」から「地域の人につなぐ」へ
  3. 3日目父に断られ、母が楽しそうに話す。福祉関係の方に電話で聞く。本物の電話、状況画面、安全テスト、家族の声の伝言
  4. 4日目家族が Claude に様子を聞ける窓口。安全テストで落ちた5場面を直す
  5. 5日目福祉関係の方から、試作の動画の感想が届く
  6. 6日目画面を、ゆげ丸の朝焼けの色にそろえる

聞き手の「ゆげ丸」は、電話番AIで毎朝の電話を受け持つ AI の名前です。このインタビューは Claude Code の上で実際に一問一答で行い、答えは本人の言葉を読みやすく整えました。

福祉関係の方は、先方の希望により団体名とお名前を伏せています。
