# 見守り電話は混んでいる。空いているのは「その先」

高齢者向けのAI見守り電話と、地域の手助けマッチングを調べ、電話番AIの立ち位置を整理しました。Web上の公開情報のみで、料金は税込・各社の発表時点です。

## 結論

**見守りの電話**

2026年だけで6サービスが登場。ここでは差がつかない

**手助けのマッチング**

高齢者が自分で電話するか、人がつなぐ形のみ

**電話番AIの勝ち筋**

毎朝の会話で困りごとを拾い、地域の協力者へ自動でつなぐ

## 電話番AIの優位性

強

### 会話から困りごとを拾い、地域の協力者へ自動でつなぐ

見守り系は通知で止まり、マッチング系は高齢者が自分で電話するか人がつなぐ。両方を毎朝の1本の電話で行うものは、調べた範囲では見当たりませんでした。

中

### 電話に出るだけ（固定電話でも使える）

Care-Call.AIやNAVERと同じ水準。LINEが前提のふれり、スマホが必須のTHIALOGよりは有利です。

中

### 家族への通知がLINE

Care-Call.AIはメールとWeb画面。ふれりはLINEで同等です。

中

### 長崎弁と雲仙の地域密着

ふれりも関西弁に対応しています。方言だけでは弱く、地域の協力者の輪と組み合わせて初めて効きます。

中

### Claudeが会話中に、通知や依頼を自分で判断する

審査の「Claudeの活用」で説明しやすい点です。利用者から見た違いではありません。

弱

### 低価格

試算では原価の大半が通話料で、毎日3分なら月1,800〜3,300円かかります。自動音声（月1,070円〜）より安くはできず、Care-Call.AI（3,980円〜）と同じか少し下が現実的です。

## 正直なリスク

- 見守りだけなら後発で勝ち目はない。大手は自治体や介護事業者への販路を持っている
- マッチングは安全の設計が要る。協力者の本人確認、事故時の責任、謝礼の扱い、連絡先の渡し方
- 本番には日本の電話番号が必要。デモのアメリカ番号は検証用と割り切る
- 体調の話は聞くだけにし、医療の助言はしない

## デモと開発への示唆

1. 見守りパートは30秒程度に縮め、マッチングを一番長く見せる
2. 会話設計に、困りごとを依頼にするツール（request_help）を足す
3. 「協力者は事前登録・本人確認済み、連絡先は受諾した1人だけに渡す」を設計に入れて触れる
4. 遅れたときの「マッチングはモックで見せる」は最後の手段にする。自動再発信より、マッチングを先に動かす

## 概要に使える一文

AIの見守り電話は、もうある。電話番AIは、その毎朝の会話を、地域の「ちょっと手伝って」につなぐ。

## 1通話あたりのコスト

3分・8往復、AIの発話600字、1ドル150円で仮置き。Twilioの日本向け料金とClaude Haiku 5.5の公開料金で試算。

**携帯へ**約$0.74 ／ 月30回で約3,300円

**固定電話へ**約$0.41 ／ 月30回で約1,800円

- 通話料
- 音声認識
- 読み上げ
- Claude（約$0.004）

### わかったこと

- 原価の55〜75%は通話料、次が音声認識。Claudeは1%前後
- 自動音声の郵便局（月1,070円〜）より安くするのは難しい
- 通話を2分に収めれば、固定電話で月約1,300円まで下がる

### お金の取り方の候補

- 月額はCare-Call.AIと同じか少し下（3,000円前後）
- マッチングの謝礼から手数料（OTERAは約3割を運営費に）
- 自治体の補助や委託（郵便局の見守りはデジ田交付金の活用例あり）

郵便局のみまもりでんわは、日本郵便の2021年8月の発表で固定電話1,070円・携帯1,280円（税込）を確認しました。それ以降の改定は確認できていません。Claude Haiku 5.5の料金は公開記事の値なので、Consoleでも確認してください。
